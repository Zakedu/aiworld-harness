## 2. 파트 인트로 탭 (6컬럼)

> 헤더: 1행, 데이터: 2행부터. 5파트 = 5행.

| 열 | 헤더 | 설명 | 제약 |
|---|---|---|---|
| A | 파트 구분 | 파트 번호 | 1~5 |
| B | 파트명 | 파트 제목 | 커리큘럼의 파트명과 동일 |
| C | [내부] 기획 의도 | 교육적 목표/기획 의도 | 이 파트가 왜 필요한지, 학습자에게 어떤 능력을 키우는지 |
| D | [내부] 에피소드 소스 | 위인의 실제 일화 + 출처 | 실제 사실 기반. 출처 명시 필수 |
| E | [네러티브] 파트 인트로 | 학습자에게 보여지는 내러티브 | 위인의 에피소드 → 학습 주제 연결. 200~300자 |
| F | [네러티브] 핵심 한 줄 | 파트 핵심 요약 | 격언 형태. 20자 내외 |

## 5. 퀴즈 탭 (12컬럼)

> 헤더: 1행, 데이터: 2행부터. 챕터당 10문항.

| 열 | 헤더 | 설명 | 제약 |

| A | 챕터 구분 | 챕터 번호 | "1-1" 형식 |
| B | clip_group_id | 클립 그룹 ID | "-" 고정 |

| F | 제목 | 문항 제목 | 75자 이하 |
| G | 문제 | 문제 본문 | 최대 150자 |
| H | 힌트 | 힌트 | 정답 직접 노출 금지 |
| I | 답안 보기 | 보기 목록 | 유형별 규칙 적용 |
| J | 정답 | 정답 | 유형별 형식 |

## 탭 간 관계

```
설정 ─── course_id로 전체 연결
  │
파트 인트로 ─── 5파트별 내러티브 + 기획 의도 (Step 1에서 생성)
  │
개요 ─── 코스 메타데이터 (Step 1에서 생성)
  │
커리큘럼 ─── 챕터 구조 + 학습자료 링크 (Step 1이 구조, Step 2가 Docs 링크)
  │
  ├── 퀴즈 ─── 챕터구분으로 커리큘럼과 연결 (Step 3이 생성)
  │
  └── 실습 ─── 챕터구분으로 커리큘럼과 연결 (Step 4가 생성)
```
