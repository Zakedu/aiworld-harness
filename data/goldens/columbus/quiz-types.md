# 퀴즈 5유형 상세 규칙

> 퀴즈 생성 시 반드시 이 규칙을 준수해야 함. 위반 시 Self-Check에서 재생성.

---

## 유형 1: OX

| 항목 | 규칙 |
|---|---|
| type | `"OX"` |
| choices | `"-"` (보기 없음) |
| answer | `"O"` 또는 `"X"` |
| category | `"-"` |
| hint | 문장형. **초성 금지** |
| question | 참/거짓 판단 가능한 명제 형태 |

**좋은 OX 문항 특징**:
- "~이다" 형태의 명확한 진술
- 미묘한 차이를 이용한 판단 유도 (단순 사실 확인 X)
- 위인의 관점에서 흔한 오해를 다루는 문항

---

## 유형 2: 단일선택

| 항목 | 규칙 |
|---|---|
| type | `"단일선택"` |
| choices | 정확히 **4개** 보기: `"(1) ...\n(2) ...\n(3) ...\n(4) ..."` |
| answer | `"(1)"` ~ `"(4)"` 중 **정확히 1개** |
| category | `"-"` |
| question | 반드시 `"~가장 적절한 것은?"` 으로 종료 |

**보기 작성 원칙**:
- 오답은 "그럴듯하지만 다른 개념" (명백한 오답 금지)
- 최소 2개 오답은 학습자가 고민할 수 있는 수준
- 보기 길이는 비슷하게 (정답만 유난히 길거나 짧지 않게)

---

## 유형 3: 복수선택

| 항목 | 규칙 |
|---|---|
| type | `"복수선택"` |
| choices | 정확히 **5개** 보기: `"(1) ...\n(2) ...\n(3) ...\n(4) ...\n(5) ..."` |
| answer | 정확히 **2개**: `"(1), (3)"` 형태 (콤마+공백) |
| category | `"-"` |
| question | 반드시 `"가장 적절한 것을 2개 고르시오"` 로 종료 |

**주의사항**:
- 정답은 반드시 2개 (1개도 3개도 안 됨)
- 5개 보기 중 2개 정답 + 3개 매력적 오답

---

## 유형 4: 분류

| 항목 | 규칙 |
|---|---|
| type | `"분류"` |
| choices | 정확히 **5개** 보기: `"(1) ...\n(2) ...\n(3) ...\n(4) ...\n(5) ..."` |
| answer | `"[1,3,5]/[2,4]"` 형태 (두 그룹으로 5개 완전 분배) |
| category | 정확히 **2개** 분류명: `"분류명1, 분류명2"` (쉼표로 구분) |
| question | 반드시 `"~로 올바르게 분류하시오"` 또는 `"~로 분류하시오"` 로 종료 |

**검증 규칙 (절대)**:
- 5개 보기 번호 (1)~(5)가 두 그룹에 **누락 없이, 중복 없이** 분배
- `[그룹A] + [그룹B] = {1,2,3,4,5}` 반드시 성립
- 분류명은 서로 대비되는 개념 (예: "효과적/비효과적", "입력/출력")

---

## 유형 5: 단답형

| 항목 | 규칙 |
|---|---|
| type | `"단답형"` |
| choices | `"-"` (보기 없음) |
| answer | 단어 또는 짧은 구/용어 |
| category | `"-"` |
| hint | 반드시 **초성 포함** + 의미 힌트 |
| question | 반드시 `"빈칸에 들어갈 단어를 쓰시오."` 로 종료 |

**힌트 작성 예시**:
- "ㅁㅎ ㅂㅇ — AI에게 구체적인 상황을 설명하는 기법을 말합니다."
- "ㅍㅅㄴ — 대화에서 AI에게 특정 역할을 부여하는 것을 말합니다."

---

## 난이도 분배 규칙

챕터당 10문항의 난이도는 아래와 같이 분배:

| 난이도 | 문항 수 | 유형 배치 권장 |
|---|---|---|
| 하 | 2문항 | OX 1 + 단답형 1 |
| 중하 | 1문항 | 단일선택 1 |
| 중 | 3문항 | OX 1 + 단일선택 1 + 복수선택 1 |
| 중상 | 2문항 | 복수선택 1 + 분류 1 |
| 상 | 2문항 | 분류 1 + 단답형 1 |

---

## Self-Check 항목 (출력 직전 검수)

1. 총 10문항인가? 각 유형이 정확히 2개씩인가?
2. 단일선택: 보기 4개인가? 정답 1개인가?
3. 복수선택: 보기 5개인가? 정답 정확히 2개인가?
4. 분류: 분류명 정확히 2개인가? 보기 5개가 두 분류에 완전 분배되는가?
5. 단답형: 힌트에 초성이 포함되었는가?
6. 해설: 모든 문항에 (정답이유/오답반박/실무예시) 3요소가 있는가?
7. 학습자료 근거 밖 내용이 섞이지 않았는가?
8. 위인 페르소나가 해설에서 일관되게 유지되는가?
