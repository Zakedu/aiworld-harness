# BestPractice 참고: 콜롬버스 코스

> 기존 콜롬버스 코스의 구조를 참고용으로 문서화.
> 새 스킬은 이 구조를 기반으로 "위인 멘토링 시뮬레이션"으로 업그레이드.

---

## 개요 탭 구조 (콜롬버스)

- **코스명**: 콜롬버스의 항해 — AI로 시장을 발견하는 트렌드 분석 보고서 작성법
- **카테고리**: 업무생산성
- **캐릭터명**: 크리스토퍼 콜롬버스
- **팔릴이유한줄**: AI로 3시간 걸리던 시장분석을 30분에 끝내는 방법
- **프로젝트결과물**: AI를 활용한 글로벌 시장 트렌드 분석 보고서
- **수강대상**: 시장분석 보고서 작성에 매번 시간이 부족한 직장인 / AI를 써봤지만 원하는 결과가 안 나온 사람 / 데이터 분석 역량을 키우고 싶은 주니어
- **수강효과**: 시장분석 소요 시간 80% 단축 / AI와의 대화에서 원하는 결과를 정확히 뽑아내는 능력 / 상사가 감탄하는 보고서 구조 설계

## 커리큘럼 구조 (콜롬버스)

| 구분 | 파트 | 챕터 | 프롬프트 기법 |
|---|---|---|---|
| 1-1 | AI와 대화 시작하기 | 맥락 없는 대화의 한계 | 맥락 부여하기 |
| 1-2 | AI와 대화 시작하기 | 맥락을 더한 효과적 대화 | 배경 정보 제공 |
| 2-1 | 역할 부여의 힘 | AI에게 전문가 역할 맡기기 | 페르소나 설정 |
| 2-2 | 역할 부여의 힘 | 역할 조합으로 깊이 더하기 | 멀티 페르소나 |
| 3-1 | 출력 형식 설계 | 구조화된 결과물 요청하기 | 출력 형식 지정 |
| 3-2 | 출력 형식 설계 | 표/차트/요약문 만들기 | 포맷 최적화 |
| 4-1 | 단계적 사고 유도 | 복잡한 문제 쪼개서 풀기 | Chain of Thought |
| 4-2 | 단계적 사고 유도 | 비교분석 프레임 활용 | 비교 분석 프롬프팅 |
| 5-1 | 종합 프로젝트 | 시장 트렌드 보고서 초안 | 종합 프롬프트 설계 |
| 5-2 | 종합 프로젝트 | 보고서 검토 및 완성 | 피드백 루프 |

## 퀴즈 스타일 (콜롬버스 — 기존)

### 제목 예시
- "맥락 없는 프롬프트와 AI의 기본 출력 특성"
- "AI 역할 부여의 효과와 한계"

### 문제 예시
- "AI에게 맥락 없이 요청할 때, 가장 적절한 설명은?"
- "다음 중 페르소나 설정에 해당하는 것을 고르시오"

### 해설 예시
- "맞습니다. AI는 맥락이 없으면 가장 평균적인 결과를 출력합니다. 구체적인 상황과 조건을 함께 제공해야 원하는 결과를 얻을 수 있습니다."

## 실습 스타일 (콜롬버스 — 기존)

### 콘텐츠명 예시
- "단순 보고서 요청하기"
- "맥락을 더해 분석 요청하기"
- "종합 프롬프트로 보고서 작성하기"

### 문제 예시
- "역할 부여 없이 단순히 보고서를 작성해 달라고 요청하시오."
- "시장분석 전문가 역할을 부여하고 구체적 조건과 함께 요청하시오."

### 평가항목 예시
- "분석 대상을 명시했나요?" / "분석 대상 기업이나 산업 이름이 포함되어야 합니다."
- "출력 형식을 지정했나요?" / "표, 요약문 등 원하는 결과 형태를 명시해야 합니다."

## 기존 vs 새 방향 핵심 차이

| 항목 | 기존 (콜롬버스) | 새 방향 (위인 멘토링) |
|---|---|---|
| 톤 | 교과서/시험 | 멘토/제자 대화 |
| 제목 | 개념 나열 | 스토리텔링 |
| 문제 | "~에 대해 적절한 것은?" | "당신이 ~한 상황에서 위인은 뭐라고 할까?" |
| 해설 | "맞습니다. ~입니다." | 위인 1인칭 + 오답별 피드백 + 실무팁 |
| 실습 | "~하시오." | "위인이 말합니다: '~해봐'" |
| 평가 | "~했나요?" (단순) | "~했나요?" (교육적 기준) |
