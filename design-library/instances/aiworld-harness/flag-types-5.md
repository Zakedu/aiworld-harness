# 플래그 5종 (AI World Harness)

공통 라이브러리의 플래그 5 카테고리를 이 프로젝트에서 어떻게 해석·적용하는지.

---

## 1. FACT — 출처·사실 확인
- **의미**: 위인 어록·일화·연도·기관명 등 팩트 의심 영역
- **트리거 예시**:
  - 설리번이 헬렌에게 한 발언 원문 출처 미상
  - 커리큘럼에 등장하는 역사적 사건 연도 틀림
  - 실제 있지 않은 위인 저서 인용
- **체크 가이드 템플릿**: "원 출처 확인 필요. 미상이면 '전해지는 말' 표기 또는 삭제"

## 2. SCHEMA — 서식 오류
- **의미**: 퀴즈 보기 개수, 실습 고정값, 테이블 컬럼 등 규격 위반
- **트리거 예시**:
  - 복수선택인데 보기가 4개 (5개여야 함)
  - 분류 퀴즈 정답이 `[1,2]/[4,5]` (3번 누락)
  - 실습 environment가 "Claude" (ChatGPT 고정인데)
- **체크 가이드**: "스키마 v1 규칙 확인 — 수동 편집 또는 재생성"

## 3. BORDERLINE — 애매함 — 사람 확인
- **의미**: LLM 검증자가 "중" 판정, 사람 눈 필요
- **트리거 예시**:
  - 멘토 톤 점수가 통과선(80) ±5 범위
  - 프롬프트 기법 설명이 적절하나 명료함 애매
- **체크 가이드**: "루브릭 [항목X]가 중 판정. 상/중 경계 재확인"

## 4. SENSITIVE — 민감 표현 가능
- **의미**: 직군·세대·성별·국적 일반화
- **트리거 예시**:
  - "30대 직장인들은 모두 바쁘다" 같은 일반화
  - 경쟁사 직접 언급
- **체크 가이드**: "민감 표현 점검. 중립 표현으로 대체 검토"

## 5. CONSISTENCY — 앞뒤 불일치
- **의미**: 기획서 vs 컴포넌트, 챕터 간 논리 모순
- **트리거 예시**:
  - 1장 학습목표 = "맥락 부여"인데 실습3 = "역할 설정"
  - 위인 페르소나가 학습자료는 근엄, 퀴즈 해설은 친근
- **체크 가이드**: "기획서의 학습목표 X와 실습 Y의 불일치. 한쪽 수정 필요"

---

## 매핑 (rubric_id → flag_type)

공통 규칙 (`data/rubric-v1.yaml`의 `flag_type_mapping`):

- `default: SCHEMA`
- `fact_check_ids`: intro.episode.source_cited, material.no_error_outputs
- `consistency_ids`: quiz.no_content_bleed, overview.figure_topic.coherence
- `sensitive_ids`: (현재 없음, 추후 추가)

루브릭에서 `verdict: MARGINAL`인 경우 자동으로 BORDERLINE으로 배정.

---

## 이 프로젝트만의 특이점

- **FACT 플래그는 거의 발생 안 함** (위인 선정 배경에 주로 나타남)
- **SCHEMA가 가장 많이 발생** — 퀴즈 복수선택 보기 수 위반이 흔함
- **BORDERLINE 비중이 높음** — 톤·일관성 관련 루브릭이 엄격해서
